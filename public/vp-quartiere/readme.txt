Plugin WordPress per la Web App del Comitato di Quartiere Villaggio Prenestino.
Permette la gestione di segnalazioni con foto, richieste di volontariato con raccolta recapiti telefonici dei cittadini, eventi, proposte e sincronizzazione degli ultimi articoli del blog.

== Installazione ==
1. Da WordPress vai su Plugin > Aggiungi nuovo > Carica plugin.
2. Seleziona il file zip "vp-quartiere.zip" e clicca "Installa adesso".
3. Clicca "Attiva plugin".
4. Troverai le nuove voci nel menu: "Eventi Quartiere", "Serve una Mano", "Segnalazioni", "Proposte Cittadini" e "Albo Volontari".
5. In "Impostazioni > App Quartiere" trovi lo stato delle API REST.
